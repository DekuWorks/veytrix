# Market Gear

Market Gear is an external charting, journal, and broker-connected product. Its public Alpaca page describes connecting an Alpaca account and using a virtual account: https://www.marketgear.com/alpaca/

This repository does not call Market Gear. No official developer API was found for automated order routing, so none is implemented. A person connects Alpaca inside Market Gear's own product. That connection is not a Veytrix execution route.

Veytrix does not send orders, keys, or private desk rows to Market Gear.
